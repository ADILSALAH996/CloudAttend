HOW IT WORKS

Attendance in four simple steps

From creating a session to recording attendance, CloudAttend keeps the entire process simple.

01

Create a Session

The teacher creates an attendance session for a class or subject.

02

Generate QR Code

CloudAttend generates a time-limited QR code for the active attendance session.

03

Students Scan

Students scan the QR code using their device to mark their attendance.

04

Attendance Recorded

The attendance record is securely stored in the cloud for the teacher to manage.
